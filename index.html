💾 Data Backup

എല്ലാ data-ഉം (users, customers, sales, purchases, collections, godowns, products, vehicles) ഒരു JSON file ആയി download ചെയ്യാം — safety backup ആയി സൂക്ഷിക്കാം.

♻️ Restore from Backup

മുമ്പ് download ചെയ്ത backup JSON file ഉപയോഗിച്ച് data തിരിച്ച് കൊണ്ടുവരാം. Backup file-ൽ ഉള്ള records, database-ൽ ഇപ്പോൾ ഉള്ള (അതേ ID ഉള്ള) records overwrite ചെയ്യും. ശ്രദ്ധയോടെ ഉപയോഗിക്കുക.

🔀 Merge Duplicate Customers

(ഉദാ: extra space വന്ന് CSV upload-ൽ ഒരേ customer രണ്ട് തവണ create ആയത്) കണ്ടെത്തി, ഒന്നാക്കി merge ചെയ്യാം — എല്ലാ Sales/Collections ഉം select ചെയ്യുന്ന customer-ലേക്ക് മാറ്റും, ബാക്കിയുള്ളവ delete ചെയ്യും.

⚠️ Bulk Delete (Test Data)

Test ചെയ്യാൻ ഉപയോഗിച്ച data ഒറ്റയടിക്ക് നീക്കാൻ. ഈ action permanent ആണ്, തിരിച്ചെടുക്കാൻ പറ്റില്ല.

📂 Bulk Upload — Customers (CSV)

CSV columns (ക്രമത്തിൽ): Name, Phone, OpeningBalance, Notes, IsPrivate(Y/N) — ആദ്യ വരി header ആയാൽ automatic ആയി skip ചെയ്യും.
IsPrivate = Y ആയാൽ, "PVT-" prefix name-ൽ automatic ആയി ചേർക്കും (Local/Private customer).

📂 Bulk Upload — Old Sales (CSV)

Columns (ക്രമത്തിൽ): Date(YYYY-MM-DD), Area, Customer, Product, Godown, VehicleNo, Qty, UnitPrice, Discount, Freight, Amount, Status(pending/approved)
Customer **പേര് മാത്രം** വച്ചാണ് match ചെയ്യുന്നത് (Area നോക്കില്ല — ഒരു customer വേറെ Area-യിലെ stock വാങ്ങിയാലും duplicate ആകില്ല). പേര് match ആകുന്നില്ലെങ്കിൽ, ആ row-ലെ Area വച്ച് പുതിയ customer create ചെയ്യും. Godown-ൽ matching stock lots ഉണ്ടെങ്കിൽ, FIFO രീതിയിൽ stock automatic ആയി കുറയും. Matching stock ഇല്ലെങ്കിൽ മാത്രം "Advance Sale" ആയി save ആകും.

📂 Bulk Upload — Old Collections (CSV)

Columns (ക്രമത്തിൽ): Date(YYYY-MM-DD), Area, Customer, Mode, Amount, Status(pending/approved), Account
Customer **പേര് മാത്രം** വച്ചാണ് match ചെയ്യുന്നത് (Area നോക്കില്ല). പേര് match ആകുന്നില്ലെങ്കിൽ, ആ row-ലെ Area വച്ച് പുതിയ customer create ചെയ്യും. Mode "Cash" അല്ലാത്തപ്പോൾ Account column-ൽ (SBI-ALPHA പോലെ) account name നൽകുക.

📂 Bulk Upload — Old Purchases (CSV)

Columns (ക്രമത്തിൽ): Date(YYYY-MM-DD), Area, Product, Godown, Vehicle, Qty, Status(pending/approved)
ഇവയുടെ Remaining Qty automatic ആയി 0 ആയി വെക്കും (പഴയ closed purchase ആയതിനാൽ).

Area users enter ചെയ്ത pending records ഇവിടെ കാണാം (Area-wise, Date-wise sort ചെയ്തത്) — Approve ചെയ്യുകയോ, ചെറിയ correction (Quick Edit) വരുത്തുകയോ, Delete ചെയ്യുകയോ ചെയ്യാം.
